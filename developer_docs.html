4. Layman Chatbot MVP Interaction Architecture

The Chatbot MVP is specifically designed so non-technical users can interact, observe agent collaboration, and approve actions with complete transparency.

1. Natural Language or Voice Input

User speaks or types in native language (e.g. "రేపు ఉదయం 10 గంటలకు సేల్స్ మీటింగ్ పెట్టు" or "Send welcome email to new leads & remind me in 2 days").

2. Multilingual Intent & Speech Router

Auto-detects language script (Telugu, Hindi, Tamil, Kannada, Malayalam, English) and maps user request to canonical business intent.

3. Live "Thought Stream" Visualizer

Renders real-time progress pills showing agent collaboration: [Sales Agent: Found 3 Leads] → [Email Agent: Drafted Welcome Letter] → [Scheduler: Set Reminder].

4. Interactive Action Confirmation Card

Presents a clean card requesting explicit confirmation before taking action: [Approve & Execute], [Modify], [Cancel].

5. Execution & Natural Response

Executes workflow step-by-step and responds with natural voice/text summary in user's native language.

5. Multilingual Engine Architecture

Native script processing for 6 core languages with expandable translation dictionary:

  • English (en) - Global Standard
  • Hindi (hi - हिन्दी) - North / Central India
  • Telugu (te - తెలుగు) - Andhra Pradesh / Telangana
  • Tamil (ta - தமிழ்) - Tamil Nadu
  • Kannada (kn - ಕನ್ನಡ) - Karnataka
  • Malayalam (ml - മലയാളം) - Kerala

8. Security, RBAC & Enterprise Compliance

  • Multi-Tenant Data Isolation: Tenant ID scoped on every database query and cache key.
  • Role-Based Access Control (RBAC): Three-tier permissions: ADMIN (full access), MANAGER (departmental access), EMPLOYEE (self-service & limited chat).
  • Prompt Injection Protection: Dual-layer input sanitizer strips unauthorized system instructions and escapes raw user queries.
  • Audit Logging: All workflow executions, agent decisions, and financial operations are written to immutable audit logs.
